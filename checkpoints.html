What changed

What did this session change? Plexiform saves your project's files at the start and end of every AI turn, so you can see each turn's changes and put files back.

Checkpoints

Checkpoints are kept inside each project's own .git folder under refs/plexiform/cp/. They stay on this computer: Plexiform never pushes them, and a normal git push doesn't send them. Your staged changes, branches and commits are never changed. Folders that are not git repositories are skipped. Untracked files that aren't ignored are saved too, so add secret files to .gitignore.
