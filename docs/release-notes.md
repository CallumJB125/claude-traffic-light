Plexiform for Mac, Windows and Linux.

**Install**
- Mac: open the .dmg (Apple Silicon: `mac-arm64`; Intel: `mac-x64`) and drag Plexiform to Applications. The first time, right-click → Open, because this build is not yet signed.
- Windows: run the .exe. If SmartScreen appears: More info → Run anyway.
- Linux: the .AppImage (`chmod +x`, then run it) or the .deb (`sudo apt install ./Plexiform-*.deb`).

Checksums are in SHA256SUMS.txt.
