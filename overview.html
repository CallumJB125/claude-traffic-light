Integrated local models

Checking for local model endpoints…

To add an endpoint, add it to local-models.json in Plexiform's data folder (userData), for example {"endpoints":[{"id":"my-box","label":"My box","url":"http://127.0.0.1:11434","kind":"ollama"}]}. kind is ollama or openai. An API key is never stored there: name an environment variable with apiKeyEnv instead.
