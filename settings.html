Connect other agents
Writes each tool's hook config so its sessions light the widget too. Anything else can run emit.js, or POST to http://127.0.0.1:47172/signal with an x-buddy-token header set to the contents of ~/.claude-traffic-light/token.

Claude integration

Adds Buddy as an MCP server for every Claude Code session, so you can ask Claude "why is my buddy amber?" or have it answer a waiting permission prompt. Writes one entry (claude-buddy) to ~/.claude.json; restart open sessions to pick it up.

Git and CI

Review requests, changes requested on your PRs, and GitHub Actions runs you started (CI on the branch you're on, deploys anywhere), checked with your own gh login about every 90 seconds while a session is open. Each shows once, for a few minutes.
Open sessions' repos are found from their git remote; add any others here.
Workflow names that count as a deploy, comma-separated.

Voice

Hold the key, ask “What's blocked?”, “What's my Claude doing?”, “How much have I spent today?” or “What happened while I was out?”, and let go. Buddy answers out loud. Speech is turned into text on this Mac; audio is never stored or sent.
Anything outside the four questions goes to your own claude login, with no tools, settings or MCP servers, capped at 5 cents a question. It sees session states and today's spend, never your code.
What the lights mean
Which signal lights which lamp, eye colours and poses now live in Lights… in the tray menu (or right-click the widget).

Spend

Every turn is priced from your transcripts at API list prices. On a subscription that's an equivalent, not a bill, and not a share of your usage window: Claude Code doesn't write that anywhere Buddy can read.
Budget
%
0 turns a budget off. Weeks start on Monday. Near it, a finished turn shows amber with money eyes; over it, red.
Runaway session
One session spending this fast turns the light pulsing red (hover Claude for its burn rate) and sends one notification that jumps to its terminal. Buddy never stops or types into a session you started. 0 turns a limit off.
