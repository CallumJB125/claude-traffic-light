Install in one line

On a Mac or Linux computer, paste this into Terminal:

curl -fsSL https://plexiform.dev/install.sh | sh

It downloads the newest build from GitHub, checks its SHA-256 against the checksum published with that release, and installs it, with no Apple Developer ID and no "can't be opened" prompt. It never uses sudo. You can read the script first; it is short. Add PLEXIFORM_CHANNEL=stable before sh to skip pre-releases.

Opening it the first time

The one-line installer above avoids this: a file fetched by curl is not marked as downloaded from the internet, so macOS does not stop it. If you download the .dmg or .zip in a browser instead, read on. The Mac beta uses ad-hoc signing, not Apple Developer ID signing or notarization, so macOS may require confirmation on first open and after an update.

On a Mac

  1. Open the .dmg download and drag {{brand.name}} into Applications. If you downloaded a .zip, open it in Finder first, then move the app into Applications.
  2. Open {{brand.name}} from Applications. If macOS says it can't check the app for malware, choose Done.
  3. If opening was blocked, open System Settings → Privacy & Security. Under Security, choose Open Anyway for {{brand.name}} and confirm when asked.
  4. Choose Open when macOS asks again. After that, open the app normally from Applications.
  5. If macOS asks to use the keychain, verify that the request is from the build you intended to open before granting access. Ad-hoc signed updates may ask again; do not approve an unexpected request.
  6. {{brand.name}} adds its hooks to Claude Code's settings the first time it runs, appending only its own entries, and turns on Open at Login (switch it off from the tray menu and it stays off). Restart any Claude Code sessions that were already running.

On macOS 14 and earlier, right-click the app and choose Open instead. If macOS says the app "is damaged" or reports a signature problem, stop, verify the checksum and re-download from the published release. Contact support if it persists; do not bypass that warning.

On Linux

  1. On Ubuntu or Debian, choose the .deb. Open the download in your Software installer, choose Install and authenticate if asked. Then open {{brand.name}} from your applications menu. Your system needs a graphical installer that supports .deb files.
  2. For AppImage, use your file manager's Properties → Permissions to allow executing the file, where that option is available, then open it.

AppImage may need FUSE support or additional system setup. If it will not open, use the .deb on a compatible system or contact support for your distribution. Do not disable the app's sandbox to get past a launch error.

Advanced: verify your download

This optional check uses Terminal. Each release lists SHA-256 checksums in SHA256SUMS.txt. Replace <file> with your downloaded file and compare the result with the matching line there:

shasum -a 256 <file>
