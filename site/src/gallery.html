Gallery

Recipes, widget characters, widget rules and setups other people made for {{brand.name}}. Each one is reviewed before it is listed. Recipes here only read: they plan and report, and never change files.

Authors' names and GitHub handles are self-declared. Add things from inside the app (Tasks → Recipes → Browse the gallery), where you see everything an item contains before it is saved.

Submit yours

Open a pull request that adds one file under gallery/items/. A check runs the same validator the app uses, and the owner reviews every item. Items are CC0-1.0 unless you choose MIT. The gallery README has the format, the review rules and how to ask for something to be taken down.

  • Add a recipe (read-only: "edits": false)
  • Add a character (no CSS)
  • Add a pack (2–12 items already in the gallery)
