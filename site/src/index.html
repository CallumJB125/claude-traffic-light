Where your data is stored and shared.

The desktop app sends no telemetry or analytics, and the widget needs no account. Its usage reader calculates tokens and cost locally without copying full conversations. Local Tasks does keep task text, messages, AI activity and replies; pending widget requests and session reports can also contain bounded content.

Your team's hub receives cards, handovers, run progress and signed-in account details. In the release candidate, supported sessions in signed-in team workspaces are automatically shared to watch and send; personal sessions stay separate. Viewers can watch, and members with write access can message. Processing a message uses the session owner's provider quota and permissions. You can stop a private-session share or disable automatic sharing.

Live session messages and replies are readable by the hub operator while relayed. Board task-inbox messages, receipts and replies are stored durably as team history; queuing does not prove agent acknowledgement or resume a run. Update and download requests reveal your IP address and app version. Cloudflare serves this website; a recent check found a Web Analytics beacon in the served privacy and download pages.

This draft summary describes prepared release-candidate sharing behavior, not a claim that the candidate is already published. Legal review, hosting analytics verification and release acceptance are pending.

Questions people ask first

Which agents does it work with?

Claude Code has the deepest support. Configured hooks can report Codex, Cursor and Gemini activity. Messaging requires a supported current runner or an explicitly configured session channel; hooks alone do not provide it for every provider.

Does it read my prompts or my code?

The usage reader reads Claude Code logs locally and keeps counts and costs. Tasks keeps task text, sent messages, AI activity and replies locally; temporary widget requests may include tool input or questions. Content you send to a team board or supported shared session can be read by its hub operator, and task-inbox messages and replies are stored there. Your chosen AI provider handles prompts and code under its own terms.

What does the app send out?

The desktop app sends no telemetry or analytics. Team boards receive the content you share; the release candidate automatically shares supported sessions associated with a signed-in team workspace. The hub operator can read shared messages and replies, and task inboxes retain them. Updates reveal IP address and app version. Website hosting includes an injected Cloudflare Web Analytics beacon. See the privacy notice for the boundaries.

Why does the first open take extra steps?

The beta isn't signed with an Apple Developer ID yet, so macOS can ask for confirmation in System Settings, including after updates. The steps are on the download page.
